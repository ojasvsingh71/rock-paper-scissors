# 🪨 Rock Paper Scissors Game ✂️📄

This is a simple **Rock Paper Scissors** game built with HTML, CSS, and JavaScript. Play against the computer and enjoy the classic game right in your browser!

## 🚀 Live Demo

[Click here to play!](https://ojasvsingh71.github.io/rock-paper-scissors/)  

## 🛠 Tech Stack

- **HTML** for structure  
- **CSS** for styling  
- **JavaScript** for logic  

## 💡 Features

- User vs Computer gameplay
- Random computer moves
- Win/lose/draw logic
- Score tracking
